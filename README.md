# MC-Assist
An Uninstaller for Mastercam




I use this command to compile the code to .exe in the PyCharm IDE

pyinstaller --noconsole --onefile --uac-admin --collect-all customtkinter --hidden-import="tktooltip" --icon="MC Assist V0.1.ico" --add-data "MC Assist V0.1.ico;." "main V0.3.1.py"

You can find the MC Assist V0.1.ico file in the MC Assist V0.1 folder.
